# Event Endpoint Management Operator Resources

View and download the samples for Event Endpoint Management.

## Contents

- [`cr-examples`](./cr-examples): sample custom resources for Event Endpoint Management
  (`eventendpointmanagement`) and the Event Gateway (`eventgateway`), for Kubernetes and OpenShift.
- [`eem-connection-info`](./eem-connection-info): a script to obtain the connection
  information (addresses and certificate) of the internal endpoints of a gateway group.
- [`gateway-certs-samples`](./gateway-certs-samples): sample scripts and resources to
  create the certificates of an Event Gateway.
